# Coffee Shop Sales Analysis Dashboard

## 📊 Project Overview
This project analyzes coffee shop sales data using Microsoft Excel to understand sales performance, customer footfall, and product purchasing patterns. The interactive dashboard presents key metrics and visualizations to support data-driven business decisions.

## 🎯 Objectives
- Analyze overall sales and customer footfall.
- Identify hourly sales trends and weekday patterns.
- Compare sales performance across store locations.
- Understand product category sales and customer preferences.
- Track key performance indicators (KPIs).

## 🛠️ Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Interactive Slicers
- KPI Cards

## 📈 Dashboard Features
- **Key Metrics:** Total Sales, Total Footfall, Average Bill per Person, and Average Order per Person.
- **Hourly Analysis:** Explore order quantity by hour.
- **Category Analysis:** Compare sales across product categories.
- **Store Performance:** Analyze sales across different store locations.
- **Product Analysis:** Identify top-selling products.
- **Daily Trends:** Examine weekday patterns.
- **Interactive Filters:** Filter dashboard results by month and day.

## 🚀 How to Use
1. Download the Excel workbook from this repository.
2. Open it in Microsoft Excel.
3. Use the available slicers and filters to explore sales performance.
4. Review the KPIs and charts to identify trends and patterns.

## 💡 Key Learnings
- Organizing and analyzing sales data in Excel.
- Creating interactive dashboards using Pivot Tables and charts.
- Tracking business KPIs and exploring sales trends.
- Presenting data in a clear, visual format.
